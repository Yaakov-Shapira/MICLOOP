# MicLoop — Claude Development Guide

## Project Overview
MicLoop is a Hebrew-first social audio app (live podcasts/"loops"). Built with Expo SDK 52 + React Native, TypeScript, Firebase, and LiveKit for real-time audio.

## Tech Stack
- **Framework:** Expo SDK 52, Expo Router (file-based navigation)
- **Language:** TypeScript (strict)
- **Auth:** @react-native-firebase/auth — Phone Auth (SMS)
- **Database:** Firebase Firestore (JS SDK v11)
- **Storage:** Firebase Storage
- **Real-time audio:** LiveKit Cloud (@livekit/react-native)
- **State:** Zustand (`store/appStore.ts`)
- **i18n:** expo-localization + i18n-js (`i18n/` folder)

## Critical Rules

### Design System
- **Always** use `constants/colors.ts` — never hardcode hex values
- **Always** use `constants/fonts.ts` — never hardcode font names
- Spacing and radii: `constants/layout.ts`
- Prototype reference: `web-preview/app.html` and `web-preview/index.html`

### RTL / Bilingual
- Hebrew is the default locale (RTL). English is the fallback (LTR).
- Use `isRTL` from `i18n/index.ts` to conditionally set `textAlign`
- Use `marginStart`/`marginEnd` instead of `marginLeft`/`marginRight`
- Use `paddingStart`/`paddingEnd` instead of `paddingLeft`/`paddingRight`
- All UI strings go through `t('key')` from `i18n/index.ts`
- Add every new string to both `i18n/he.ts` AND `i18n/en.ts`

### Security — LIVEKIT SECRETS
- `LIVEKIT_API_KEY` and `LIVEKIT_API_SECRET` must NEVER appear in the Expo app
- They belong ONLY in `functions/.env.local` (local) and Firebase Secret Manager (production)
- LiveKit tokens are always generated by Cloud Functions — never client-side
- The `.env` file at the root contains only `EXPO_PUBLIC_*` keys (safe for client bundle)

### Audio
- `UIBackgroundModes: ['audio', 'voip']` must stay in `app.json` — required for live rooms to work when screen locks on iOS
- Request mic permissions before recording: `Audio.requestPermissionsAsync()`
- LiveKit connection lives in `hooks/useLiveKit.ts` — always disconnect on unmount

### Firebase Cloud Functions
- Functions are in `functions/src/index.ts`
- Deploy: `cd functions && npm run build && firebase deploy --only functions`
- Local dev: `firebase emulators:start --only functions`
- All functions use `{ secrets: ['LIVEKIT_API_KEY', 'LIVEKIT_API_SECRET'] }` option

### Gate Pattern
- Browsing the feed works without auth
- Actions that require auth (create loop, join, like, chat) call `showGate()` from `useAppStore`
- `GateModal` is globally mounted in `app/_layout.tsx`

## Directory Structure

```
app/             Expo Router screens
  (auth)/        Auth flow (phone + SMS)
  (tabs)/        Main 4-tab navigation
  room/[id].tsx  Live room screen
components/
  feed/          Home feed components
  room/          Live room components
  shared/        Reusable UI (GlassCard, Avatar, Toast, GateModal)
hooks/           Custom React hooks
lib/             Firebase / LiveKit helpers
store/           Zustand global state
i18n/            Translations (he + en)
constants/       Design tokens
types/           TypeScript interfaces
functions/       Firebase Cloud Functions (server-side only)
web-preview/     Original HTML prototype (reference only — do not modify)
```

## Common Tasks

### Add a new screen
1. Create file in `app/` following Expo Router conventions
2. Add all strings to both `i18n/he.ts` and `i18n/en.ts`
3. Use `Colors`, `Fonts`, `Radii`, `Spacing` from constants
4. Wrap with `<SafeAreaView>` from `react-native-safe-area-context`

### Add a new Firestore query
1. Add the helper function to `lib/firestore.ts`
2. If it's a real-time subscription, return an `Unsubscribe` function
3. Call it in a `useEffect` with proper cleanup

### Add a new Cloud Function
1. Add to `functions/src/index.ts`
2. Always verify `request.auth` first
3. Add a corresponding caller in `lib/livekit.ts` or a new lib file
4. Use `httpsCallable` from Firebase JS SDK

### Change a color or font
- Edit `constants/colors.ts` or `constants/fonts.ts`
- Do NOT use inline hex values

## Running Locally

```bash
# Install dependencies
npm install
cd functions && npm install && cd ..

# Start Expo dev server
npx expo start

# Scan QR with Expo Go app on your phone
# OR press 'i' for iOS Simulator, 'a' for Android Emulator
```

## Deploying Cloud Functions

```bash
cd functions
npm run build
firebase deploy --only functions
```

## Building for App Store

```bash
# Install EAS CLI
npm install -g eas-cli

# Login
eas login

# Build iOS (requires Apple Developer account)
eas build --platform ios --profile production

# Build Android
eas build --platform android --profile production

# Submit to stores
eas submit --platform ios
eas submit --platform android
```
